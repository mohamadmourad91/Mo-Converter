# Privacy policy · Datenschutzerklärung · سياسة الخصوصية

Last updated / Stand / آخر تحديث: 2026-11-14

## English

**Mo Converter does not collect personal data.**

- **Your files** are processed on your computer only. They are never uploaded, copied to a server or shared.
- **No accounts, no analytics, no advertising, no tracking.** Mo Converter contains no telemetry.
- **What is stored on your computer:** your settings (`settings.json`) and a small error log (`app-errors.log`, at most about 0.5 MB, which can mention file names when something fails) in `%AppData%\Mo Converter`. Neither is ever sent anywhere. Delete the folder to remove them.
- **Network use:** the installer version asks GitHub Releases whether a newer version exists and downloads it. GitHub therefore sees your IP address and the request, like for any download (see [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)). The Microsoft Store version does not check for updates itself; the Store does.
- **Other programs:** if LibreOffice is installed, Mo Converter starts it on your computer to convert office documents. Text recognition uses the recognizer built into Windows. Neither sends your files anywhere.

Questions: open an issue at <https://github.com/mohamadmourad91/Mo-Converter/issues>.

## Deutsch

**Mo Converter erhebt keine personenbezogenen Daten.**

- **Ihre Dateien** werden nur auf Ihrem Computer verarbeitet. Sie werden nie hochgeladen, auf einen Server kopiert oder weitergegeben.
- **Keine Konten, keine Analyse, keine Werbung, kein Tracking.** Mo Converter enthält keine Telemetrie.
- **Was auf Ihrem Computer gespeichert wird:** Ihre Einstellungen (`settings.json`) und ein kleines Fehlerprotokoll (`app-errors.log`, höchstens etwa 0,5 MB; bei Fehlern können Dateinamen darin stehen) in `%AppData%\Mo Converter`. Beides wird nie irgendwohin gesendet. Löschen Sie den Ordner, um es zu entfernen.
- **Netzwerk:** Die Installer-Version fragt bei GitHub Releases nach einer neueren Version und lädt sie herunter. GitHub sieht dabei Ihre IP-Adresse und die Anfrage, wie bei jedem Download (siehe [Datenschutzerklärung von GitHub](https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement)). Die Version aus dem Microsoft Store sucht selbst nicht nach Updates; das erledigt der Store.
- **Andere Programme:** Ist LibreOffice installiert, startet Mo Converter es auf Ihrem Computer, um Office-Dokumente umzuwandeln. Die Texterkennung nutzt die in Windows eingebaute Erkennung. Beides sendet keine Dateien irgendwohin.

Fragen: eröffnen Sie ein Issue unter <https://github.com/mohamadmourad91/Mo-Converter/issues>.

## العربية

**لا يجمع Mo Converter أي بيانات شخصية.**

- **ملفاتك** تُعالَج على جهازك فقط. لا تُرفع ولا تُنسخ إلى خادم ولا تُشارَك.
- **لا حسابات ولا تحليلات ولا إعلانات ولا تتبّع.** لا يحتوي Mo Converter على أي قياس عن بُعد.
- **ما يُخزَّن على جهازك:** إعداداتك (`settings.json`) وسجل أخطاء صغير (`app-errors.log`، بحد أقصى نحو 0.5 ميغابايت، وقد يذكر أسماء ملفات عند حدوث خطأ) في `%AppData%\Mo Converter`. لا يُرسَل أيٌّ منهما إلى أي مكان. احذف المجلد لإزالتهما.
- **استخدام الشبكة:** نسخة المثبّت تسأل GitHub Releases عن وجود إصدار أحدث وتنزّله، فيرى GitHub عنوان IP الخاص بك والطلب كما في أي تنزيل (انظر [بيان الخصوصية لدى GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)). نسخة Microsoft Store لا تفحص التحديثات بنفسها، فالمتجر هو من يفعل ذلك.
- **برامج أخرى:** إن كان LibreOffice مثبّتًا فإن Mo Converter يشغّله على جهازك لتحويل مستندات Office. والتعرّف على النص يستخدم المحرك المدمج في Windows. ولا يرسل أيٌّ منهما ملفاتك إلى أي مكان.

للأسئلة: افتح بلاغًا (Issue) على <https://github.com/mohamadmourad91/Mo-Converter/issues>.
